# Привет! Я развиваюсь в направлении 1С-разработки 👋

Изучаю и осваиваю разработку на платформе **1С:Предприятие 8.3**. Работаю с объектами конфигурации, встроенным языком BSL, языком запросов и механизмами платформы. Выполняю учебные и практические проекты, формируя портфолио 1С-разработчика.

## 🛠 Технологии и инструменты

- **Платформа:** 1С:Предприятие 8.3
- **Языки:** встроенный язык 1С (BSL), язык запросов 1С
- **Механизмы платформы:** справочники, документы, регистры, подсистемы, управляемые формы
- **Отчётность:** система компоновки данных (СКД), макеты и печатные формы
- **Инструменты:** Git, GitHub
